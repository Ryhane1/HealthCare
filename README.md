# 🏥 HealthCare+ — API REST de Gestion Médicale

## 📌 Description

HealthCare+ est une API REST développée avec **Spring Boot** permettant la gestion complète d’un système médical.

L’application facilite :
- la gestion des patients,
- la gestion des médecins,
- la planification des rendez-vous,
- la gestion des dossiers médicaux.

Ce projet a été réalisé dans le cadre du brief **Développeur Web & Web Mobile**.
